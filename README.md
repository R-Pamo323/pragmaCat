# PragmaCat

Proyecto de ejercicio de acercamiento al rol de Pragma, realizado en **Flutter** con el gestor de estados **Bloc/Cubit**

La aplicación consume la API pública de "TheCatAPI"

## Tecnologías

- **Flutter**
- **Bloc / Cubit**
- **Dio**
- **Clean Architecture**
